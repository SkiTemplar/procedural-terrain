# Hito 1 — Base (ventana, cámara, grid, ImGui) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ejecutable que abre ventana GL 4.6, cámara voladora WASD+ratón, terreno placeholder flat-shaded e ImGui con FPS/wireframe.

**Architecture:** Módulos `core/` (ventana+input+tiempo), `render/` (shader, mesh, cámara), `terrain/` (grid placeholder), `ui/` (ImGui). El main es un game-loop fino que cablea módulos. Flat shading vía `dFdx/dFdy` en fragment shader (sin duplicar vértices).

**Tech Stack:** C++20, OpenGL 4.6 core, GLFW, GLAD, GLM, ImGui (bindings glfw+opengl3), vcpkg manifest, CMake+Ninja, GoogleTest (se estrena en Hito 2).
